# 微信小程序企业认证 & 支付接入 TODO

> 前提：已注册小规模核定征收公司

## 1. 注册企业主体小程序

- [ ] 进入 [微信公众平台](https://mp.weixin.qq.com/) → 立即注册 → 小程序
- [ ] 选择主体类型：企业（个体工商户）
- [ ] 填写企业信息：营业执照编号、法人姓名、身份证号
- [ ] 绑定管理员微信号
- [ ] 记录新 AppID（替换当前个人主体 `wx4c13a86301c69501`）

## 2. 微信认证（300 元/年）

- [ ] 小程序管理后台 → 设置 → 基本设置 → 微信认证 → 开始认证
- [ ] 选择认证类型：企业/个体工商户
- [ ] 上传资料：营业执照照片、法人身份证正反面
- [ ] 支付 300 元审核费
- [ ] 等待审核（1-3 个工作日，审核公司会电话联系法人核实）
- [ ] 审核通过 → 认证完成

## 3. 申请微信支付商户号

- [ ] 进入 [微信支付商户平台](https://pay.weixin.qq.com/) → 成为商家
- [ ] 提交资料：营业执照、法人身份证、结算银行账户（可用法人个人银行卡）
- [ ] 等待审核（1-3 个工作日）
- [ ] 完成打款验证（微信打小额到你的账户，回填金额）
- [ ] 在线签署合作协议
- [ ] 记录商户号 `mch_id`、API v3 密钥、商户证书 + 私钥

## 4. 绑定小程序

- [ ] 商户平台 → 产品中心 → AppID 绑定 → 填入新小程序 AppID
- [ ] 小程序管理后台 → 设置 → 第三方设置 → 确认绑定

## 5. 代码更新

- [ ] 更新 `apps/miniprogram/project.config.json` 中的 `appid` 为新企业 AppID
- [ ] 后端接入 `wechatpay-node-v3` SDK，替换模拟支付逻辑
- [ ] 配置商户号相关环境变量（`WX_MCH_ID`、`WX_API_V3_KEY`、证书路径）
- [ ] 测试支付流程
